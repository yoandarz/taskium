TASKIUM 2.1.0 - PRUEBA DE ALARMAS LOCALES

WINDOWS
1. Publica Taskium 2.1.0 en GitHub Pages.
2. Ejecuta TaskiumAlarmBridge.exe una sola vez.
3. Abre Taskium. En Alarmas debe indicar: Windows · alarma local.
4. Pon una hora 2-3 minutos por delante. Al cambiar la hora, la casilla se activa automáticamente.
5. Cierra Taskium. A la hora prevista debe abrirse una ventana de Taskium aunque No molestar esté activo.

ANDROID
1. Instala el APK nativo de Taskium.
2. Inicia sesión y sincroniza.
3. Pulsa Activar alarmas locales y concede notificaciones + alarmas exactas si Android lo solicita.
4. Programa una hora 2-3 minutos por delante.
5. Cierra la app. Android debe mostrar la notificación local a la hora programada.
